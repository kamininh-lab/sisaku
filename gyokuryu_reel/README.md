# 鹿児島玉龍高校「進学相談会」Instagramリール

- `gyokuryu_shingaku_reel.mp4` … 完成動画（1080×1920 / 30fps / 27秒・無音トラック付き。BGMはInstagram側で追加）
- `reel.html` … 動画の元データ（ブラウザで開くとループ再生でプレビュー可）
- `render.js` … MP4 書き出し（`node render.js`、Playwright と ffmpeg が必要）
- `assets/` … 告知チラシから切り出した素材（校章・ポスター）

## 構成
| 秒 | 内容 |
|---|---|
| 0–3.4 | フック「高校選び、もう始めていますか？」 |
| 3.4–7.6 | タイトル「進学相談会」 |
| 7.6–11.4 | こんな方へ（チェックリスト2項目） |
| 11.4–14.6 | 学校紹介ポスター |
| 14.6–19.2 | 日時・会場・プログラム |
| 19.2–22.4 | 先着50組・親子参加OK・駐車場あり |
| 22.4–27 | 申込締切とプロフィールリンクへの誘導 |

# ストーリーズ用アニメーション（15秒）

|---|---|---|

- 元データ：`story.html?v=1` または `?v=2`（書き出し：`node render.js story_1115.mp4 story.html v=1`）
- 構成：0–3.4秒 タイトル（要申込）→ 3.4–7.2秒 日時・会場 → 7.2–10.6秒 内容・先着50組 → 10.6–15秒 締切と申込の案内
- **リンクスタンプは「▼▼」の下にある空き（画面の下から4分の1あたり）に貼ってください**
- 運用：11/12までは `story_1115`、11/13以降は `story_1206` を使います。締切前日にも再投稿すると効果的です。
